Run one lecture from this directory, which is the `code` folder of time-series-labs.zip: `uv run python ch01.py`, `Rscript ch01.R`, or `julia --startup-file=no ch01.jl`. A chapter entry point cannot run on its own; it loads the course file and data beside it. Python setup: `uv sync --locked`. R/Julia core examples use standard libraries. Complete source is in course.py, course.R, course.jl. The small chapter entry points call these exact implementations.

Run the three connected public projects: projects.py, projects.R, or projects.jl. This is a worked practice case; live forms, holdouts, and keys are excluded. The two-month release lag is an explicit teaching assumption, and observed data use one fixed downloaded vintage. See data/texas-manifest.json.

Run all three languages concurrently: `uv run python verify.py`. It checks shared hashes, analytic identities, explicit failures, all 152 lecture quantities, 13 project quantities, and 276 matched forecast rows. Numerical agreement does not prove common economic assumptions. The report is results/verification.json.

Conventions: plus sign on MA coefficients; conditional ARMA/GARCH grids explicitly identified as coarse estimators; QR least squares; sample covariance denominators documented; forecast origin and target retained; missing measurements skip filter update; smoother uses future information deliberately.

The fixed innovations were generated by Park–Miller LCG and Box–Muller with seed 515; all languages read the same CSV. The Lecture 6 Monte Carlo uses 2,000 replications per design drawn from a single stream with seed 2026, split into consecutive blocks. It never reseeds a replication: with a multiplicative generator, consecutive seeds give nearly equal first draws, and the replications would not be independent. Source paths are relative. Figures are recreated by figures.py. Provider extraction needs openpyxl 3.1.5; ordinary course execution does not need provider access or API credentials.

The public outputs retain negative findings: seasonal naive narrowly beats the repaired calendar model on the 2025 continuation targets. Preserve that result when reproducing this edition. Those twelve targets are EIA Preliminary values, while every earlier target is Final (column eia_status). A uniform upward revision of less than 0.1 percent to the 2025 values would equalize the two RMSEs, so the ranking should be rescored once EIA publishes final 2025 data.

The Lecture 2 risk-state counterexample is in risk-example.py, risk-example.R, and risk-example.jl. Run `uv run python verify-risk.py` to compare exact finite enumerations and horizon boundaries. The results/risk-verification.json report records 42 matched metrics, nine analytic targets, and fifteen finite-sum/closed-form checks. Run `uv run python lesson-figures.py` to recreate the original two-step forecast graphic. This exercise is public practice; it contains no live assessment forms or keys.
