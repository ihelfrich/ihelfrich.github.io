Run one lecture: `uv run python ch01.py`, `Rscript ch01.R`, or `julia --startup-file=no ch01.jl` from this directory. Python setup: `uv sync --locked`. R/Julia core examples use standard libraries. Complete source is in course.py, course.R, course.jl. The small chapter entry points call these exact implementations.

Run the three connected public projects: projects.py, projects.R, or projects.jl. This is a worked practice case; live forms, holdouts, and keys are excluded. The two-month release lag is an explicit teaching assumption, and observed data use one fixed downloaded vintage. See data/texas-manifest.json.

Run all three languages concurrently: `uv run python verify.py`. It checks shared hashes, analytic identities, explicit failures, all 112 lecture quantities, 13 project quantities, and 276 matched forecast rows. Numerical agreement does not prove common economic assumptions. The report is results/verification.json.

Conventions: plus sign on MA coefficients; conditional ARMA/GARCH grids explicitly identified as coarse estimators; QR least squares; sample covariance denominators documented; forecast origin and target retained; missing measurements skip filter update; smoother uses future information deliberately.

The fixed innovations were generated by Park–Miller LCG and Box–Muller with seed 515; all languages read the same CSV. Source paths are relative. Figures are recreated by figures.py. Provider extraction needs openpyxl 3.1.5; ordinary course execution does not need provider access or API credentials.

The public outputs retain negative findings: seasonal naive narrowly beats the repaired calendar model on the 2025 continuation targets. Preserve that result when reproducing this edition.

The Lecture 2 risk-state counterexample is in risk-example.py, risk-example.R, and risk-example.jl. Run `uv run python verify-risk.py` to compare exact finite enumerations and horizon boundaries. The results/risk-verification.json report records 42 matched metrics, nine analytic targets, and fifteen finite-sum/closed-form checks. Run `uv run python lesson-figures.py` to recreate the original two-step forecast graphic. This exercise is public practice; it contains no live assessment forms or keys.
